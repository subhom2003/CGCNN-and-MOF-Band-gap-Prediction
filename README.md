# QMOF-CGCNN: Crystal Graph Convolutional Neural Networks for MOF Bandgap Prediction
**ML4Science 2025 Workshop Project**

## Overview
This project implements CGCNN (Crystal Graph Convolutional Neural Networks) as described in Xie & Grossman, PRL 120, 145301 (2018) to predict PBE bandgaps of Metal-Organic Frameworks (MOFs). The pipeline covers data loading, graph construction, preprocessing, training, evaluation, and baseline models.

## 1) One-Time Setup

### Install dependencies
```bash
bash setup.sh
# or manually:
pip install -r requirements.txt
```

### Activate virtual environment
```bash
source .venv/bin/activate
```

### Place your data
Copy your files into `data/raw/`:
```bash
cp /path/to/qmof.csv   data/raw/
cp /path/to/*.cif      data/raw/cifs/
```
- `qmof.csv` must contain columns: `id`, `formula`, `bandgap`, `pld`, `lcd`, `density`, `energy_total`, and optionally `energy_per_atom`
- `.cif` files must be named `{id}.cif` (e.g., `qmof-8a95c27.cif`)

## 2) Configuration — The New Way
All hyperparameters are stored in `configs/default.json`. You can:

### Edit `configs/default.json` directly
Change any field (learning rate, epochs, cutoff, model architecture, etc.) and the pipeline will use those values.

### Override via CLI
Any CFG field can be overridden from the command line:
```bash
python -m src.train --lr 0.001 --epochs 10 --hidden 256 --cutoff 5.0
```
Boolean flags accept `true/false/1/0/yes/no`:
```bash
python -m src.train --use_energy false --linear_pool true
```
Tuple fields use comma-separated format:
```bash
python -m src.train --fc_hidden 128,64
```

### Print current config
```bash
python -m src.train --print_config
```
This dumps the full effective configuration (JSON defaults + CLI overrides).

## 3) Pipeline Stages

The pipeline is orchestrated by `run_pipeline.sh`. Typical usage:

### Dry run (smoke test — small subset, fast)
```bash
bash run_pipeline.sh --smoke_test true --epochs 5
```
- Runs all 7 stages with 1/20 of the training data
- Completes in ~1-2 minutes
- Great for verifying the setup works

### Full run
```bash
bash run_pipeline.sh
```
- Processes all CIFs, builds graphs once (5–15 min on CPU), trains for specified epochs
- On GPU: training ~1.5–4 hours for 300 epochs

### Skip slow extras (baselines/interpreter)
```bash
SKIP_BASELINES=1 SKIP_INTERPRET=1 bash run_pipeline.sh
```

### Custom overrides
```bash
bash run_pipeline.sh --cutoff 5.0 --batch_size 32 --use_energy false --seed 7
```

### Pipeline stages (1–7):
1. **Data loading** (`data_loading.py`) — Clean raw CSV, save `qmof_clean.csv`
2. **EDA** — Exploratory data analysis plots
3. **Graph builder** (`graph_builder.py`) — Convert CIFs to PyG graph cache
4. **Preprocessing** (`preprocessing.py`) — Splits, scaler, median imputation
5. **Train** (`train.py`) — CGCNN training with early stopping
6. **Evaluate** — Test set MAE/RMSE/R2
7. **Baselines** — Mean predictor + GradientBoostingRegressor

## 5) Hyperparameter Reference (`configs/default.json`)
All CFG fields are listed below. Edit this JSON file or override via CLI.

```json
{
  "raw_csv": "data/raw/qmof.csv",
  "cif_dir": "data/raw/cifs",
  "processed_csv": "data/processed/qmof_clean.csv",
  "graph_cache": "outputs/graphs/graphs.pt",
  "natoms_map": "outputs/graphs/natoms_map.json",
  "splits_dir": "outputs/splits",
  "model_dir": "outputs/models",
  "figures_dir": "outputs/figures",
  "metrics_dir": "outputs/metrics",
  "predictions_dir": "outputs/predictions",
  "logs_dir": "logs",
  "id_col": "id",
  "target": "bandgap",
  "metal_thr": 0.1,
  "cutoff": 6.0,                     # neighbor radius (A), MOF-safe
  "max_neighbors": 30,               # max neighbors per node
  "gauss_bins": 41,                  # Gaussian edge-feature resolution
  "max_natoms": 800,                 # max atoms per CIF
  "n_jobs": 8,                       # parallel CIF parsing
  "hidden": 128,                     # CNN hidden dimension
  "n_conv": 3,                       # number of convolutional layers
  "fc_hidden": [128, 64],            # fully connected hidden layers
  "dropout": 0.0,                    # dropout rate
  "conv_type": "modified",           # "modified" = Eq.(5) | "simple" = Eq.(4)
  "use_aux": true,                   # fuse pld/lcd/density/e-per-atom
  "use_energy": true,                # include energy_total/atom (DFT-derived!)
  "linear_pool": false,              # interpretable linear-pooling head
  "optimizer": "adamW",              # "sgd" (paper) | "adamw"
  "lr": 0.01,                        # learning rate
  "momentum": 0.9,                   # SGD momentum (ignored for AdamW)
  "weight_decay": 0.00001,           # L2 regularization
  "batch_size": 64,                  # training batch size
  "epochs": 300,                     # total training epochs
  "lr_gamma": 0.98,                  # exponential LR decay gamma
  "grad_clip": 5.0,                  # gradient clipping norm
  "patience": 40,                    # early stopping patience epochs
  "num_workers": 0,                  # DataLoader workers
  "seed": 42,                        # random seed
  "smoke_test": false,               # train on small subset
  "model_path": "",                  # "" -> model_dir/best_model.pt
  "skip_ablations": false,           # skip ablation studies
  "ids": "",                         # comma-separated ids for predict
  "ids_file": ""                     # csv with an ID column for predict
}
```

## 6) Troubleshooting

### Common errors & fixes

| Error | Cause | Fix |
|---|---|---|
| `KeyError: ['pld_missing', 'lcd_missing'] not in index` | `table.csv` missing `pld_missing`/`lcd_missing` columns | Fixed — ensure preprocessing ran successfully |
| `RuntimeError: Tensors must have same number of dimensions` | Aux tensor shape mismatch in model forward | Fixed — `.unsqueeze(0)` added to aux tensor |
| `DtypeWarning: Columns have mixed types` | harmless — specifies `low_memory=False` or dtype | Normal, does not affect results |
| `KeyError: some CIF files missing` | Some `{id}.cif` files not found in `data/raw/cifs/` | Ensure all IDs have corresponding `.cif` files |
| `CUDA out of memory` | Batch size too large for GPU | Reduce `--batch_size` in CLI or `configs/default.json` |

### If you modify `configs/default.json`
- Delete `outputs/splits/` and `outputs/graphs/` if switching between drastically different settings (e.g., changing `cutoff` or `use_energy`)
- The scaler and splits are computed from the full dataset; changing aux columns after splits are generated may cause mismatches
